# 📌 Sobre o projeto

O **SAC Inteligente IA** foi desenvolvido para simular uma central moderna de atendimento automatizado para jornais e plataformas de assinatura digital.

O sistema possui:

- onboarding inteligente
- atendimento via IA
- URA digital interativa
- fluxo de assinatura
- fluxo para clientes assinantes
- integração com OpenAI
- validação de dados
- integração ViaCEP
- simulação de pagamentos
- sistema de protocolos
- atendimento contextual por setor

# 🚀 Como executar o projeto

## Clone o repositório

```bash
git clone https://github.com/izadantasnunes/sac-inteligente-ia.git
```

---

## Entre na pasta

```bash
cd sac-inteligente-ia
```

---

## Instale as dependências

```bash
pip install -r requirements.txt
```

---

## Configure o .env

Crie um arquivo:

```env
.env
```

E adicione:

```env
OPENAI_API_KEY=sua_chave_aqui
```

---

## Rode o projeto

```bash
python app.py
```
